# MatchPulse — Live Match Center

Pulselive-style sports web app (Next.js + TypeScript + SASS).  
Track fixtures, open a match page with a timeline, and browse teams.

## Tech
Next.js (App Router), TypeScript, SASS, SWR (or fetch), accessible components.

## Scripts
- `npm run dev` – start dev server
- `npm run build` – production build
- `npm run start` – serve build
- `npm run lint` – lint
